# 10 ошибок бизнеса на Яндекс Картах — и как их исправить

*Материал по слову «КАРТЫ» для серии роликов «Ошибка №…». Николай Вертий, агентство 360-digital. Основа — практика агентства и выступление на Суровом Питерском форуме.*

Как пользоваться: откройте свою карточку в Яндекс Картах (с телефона, как клиент) и пройдите по списку. Каждая галочка — минус одна причина, по которой клиент уходит к соседу.

---

## 1. Не собираете отзывы
- [ ] Попросите лично каждого довольного клиента: администратор, мастер, официант — «Вам понравилось? Оставите пару слов?»
- [ ] Поставьте QR-код на отзыв и используйте готовые промоматериалы из кабинета Яндекс Бизнеса.
- [ ] Попросите оставлять отзыв с выключенным VPN и на месте — отзывы «издалека» часто не проходят модерацию.
- [ ] ❌ Нигде не пишите «скидка / подарок за отзыв» — это нарушение правил Яндекса.
- [ ] Отвечайте на каждый отзыв: быстро, по-человечески, без шаблонов.

## 2. Включаете рекламу на неготовую карточку
- [ ] Все разделы заполнены: описание, прайс, фото, часы, контакты, особенности.
- [ ] Свежие отзывы есть, на негатив отвечено.
- [ ] Рейтинг — по нише: для большинства ниш ориентир 4,8+, для бьюти — 5,0 (из практики агентства).
- [ ] Только после этого — реклама. Иначе люди заходят, уходят, растут отказы, и карточка падает в выдаче.

## 3. Нет дизайна, бардак в фото
- [ ] Шапка, сторис, витрина — в одном фирменном стиле.
- [ ] Раз в неделю проверьте, какое фото показывается первым: фото из отзывов клиентов часто встают наверх.
- [ ] Загружайте только свежие и красивые фото, регулярно.
- [ ] В сторис — актуальные акции и новости.

## 4. Прайс отпугивает
- [ ] Услуги разбиты по категориям.
- [ ] На каждой позиции — своё фото, не из интернета.
- [ ] Названия и описания — словами клиента («сборный букет из пионов», а не «букет №3»).
- [ ] Цены указаны (хотя бы «от»).
- [ ] Этот же прайс загружен в 2ГИС и другие площадки.

## 5. Неактуальная информация
- [ ] Телефон, сайт, часы работы, адрес, вход — всё верно.
- [ ] Данные подтверждены — есть галочка «Информация подтверждена владельцем». Без обновления её снимают примерно через 3 месяца.
- [ ] Заполнены все доступные категории.
- [ ] Отмечены особенности: парковка, детская комната, оплата картой и т. д. — по ним Яндекс подбирает вас под запросы.

## 6. Не следите за рейтингом сайта
- [ ] Найдите свой сайт в Яндексе — посмотрите, какой рейтинг показывается рядом.
- [ ] Рейтинг сайта растёт вместе с репутацией карточки: отзывы, ответы, работа с негативом.
- [ ] Попросите довольных клиентов оставить отзыв через значок рейтинга рядом с сайтом.

## 7. Реклама настроена «как получилось»
- [ ] В рекламе есть конкретная акция.
- [ ] Есть кнопка действия: записаться, позвонить, маршрут.
- [ ] В объявлениях — разные ключевые запросы, а не одно слово на всё.
- [ ] Витрина и баннер заполнены — клиенту есть за что зацепиться.

## 8. Нет аналитики
- [ ] Подменный номер в карточке — видно, сколько звонков пришло с карт (подключается, в том числе, в подписке Яндекс Бизнеса).
- [ ] UTM-метки во всех ссылках — видно переходы на сайт.
- [ ] Раз в неделю проверяйте позиции по 3–5 главным запросам в режиме инкогнито.
- [ ] Ведите простую таблицу: неделя → позиции → звонки с подменного номера → заявки с сайта по меткам.

## 9. Карточка «неживая»
- [ ] Каждую неделю: ответы на отзывы, обновление данных, публикация или событие.
- [ ] Просите клиентов строить маршрут через Карты и оставлять отзывы.
- [ ] Новые фото — регулярно.

## 10. Игнорируете негатив
- [ ] Сначала — проверьте, нарушает ли отзыв правила, и подайте жалобу.
- [ ] Не получилось удалить — ответьте: спокойно, без оправданий. Что случилось, что исправили, как связаться.
- [ ] Помните: ответ читает не автор отзыва, а будущие клиенты.
- [ ] Не бойтесь негатива — это бесплатная обратная связь.
