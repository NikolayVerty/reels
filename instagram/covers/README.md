# Обложки рилсов

Формат 1080×1920 (9:16). В сетке профиля Instagram показывает центр 3:4 (примерно y 240–1680), поэтому заголовок и лицо держим внутри этой зоны.

Стиль: бумага в клетку, Manrope 800, жёлтое выделение ключевого слова (#FFC24B), вырезанный спикер с белой обводкой-наклейкой, стикер с цифрой.

Сборка: вырезка спикера из кадра выступления (`rembg`, модель `u2net_human_seg`) → `covers.py <папка>` создаёт HTML → `node shot.js <папка>` снимает PNG через Playwright. Шрифты — из `video-projects/*/assets/fonts`.
