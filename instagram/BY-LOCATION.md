# Сценарии по локациям

Снимаем пачками: приехали в локацию — записали все её ролики за один раз.
Подача: энергично, быстро, мат точечно. 25–35 секунд. Призыв везде «КАРТЫ».
Схема каждого: первая фраза (страх потерять / любопытство) → нагнетание → повторная зацепка → суть → фраза-скриншот → «КАРТЫ».

Ролики 1–10 из `REELS-10.md` никуда не делись — они распределены ниже по смыслу.

# 🔧 Автосервис

## А1 · «Ты платишь за рекламу и не знаешь, работает ли она»
```
Ты платишь Яндексу за рекламу и не знаешь, работает ли она.
Зелёная точка горит, деньги списываются, а звонков — как будто столько же.
Знакомо? А теперь внимание.
Яндекс Бизнес даёт бесплатный подменный номер при любой рекламной кампании.
Ставишь его в карточку — и видишь каждый звонок: кто звонил, когда, сколько говорили, какие пропустили.
Раз в неделю слушай пару записей. Узнаешь, как твой мастер посылает клиентов нахрен по телефону.
Реклама без подменного номера — это как ремонт без диагностики: на глаз и на удачу.
Пиши «КАРТЫ» — пришлю, как это настроить.
```
**Экран:** ПЛАТИШЬ ЗА РЕКЛАМУ ВСЛЕПУЮ · ПОДМЕННЫЙ НОМЕР БЕСПЛАТНО · ВИДНО КАЖДЫЙ ЗВОНОК · СЛУШАЙ ЗАПИСИ · РЕМОНТ БЕЗ ДИАГНОСТИКИ
**Кадр:** вы у подъёмника; вставка — экран статистики звонков (свой/демо). **Обложка:** «РЕКЛАМА ВСЛЕПУЮ»


## К2 · «Ответил пациенту в отзыве — и нарушил закон»
```

В отзыве ты отвечаешь не пациенту. Ты отвечаешь всем. Включая юристов.
Пиши «КАРТЫ» — пришлю безопасные шаблоны ответов.
```
**Экран:** НАРУШИЛ ЗАКОН · «ВЫ ПРИШЛИ С ГАСТРИТОМ» · ВРАЧЕБНАЯ ТАЙНА · НИКАКИХ ДИАГНОЗОВ · ПОДРОБНОСТИ — ЛИЧНО
**Кадр:** вы на ресепшене, «печатаете» ответ, потом стираете. **Обложка:** «ТАК ОТВЕЧАТЬ НЕЛЬЗЯ»
⚠️ Перед публикацией показать юристу клиники формулировку про врачебную тайну. Пример условный.
