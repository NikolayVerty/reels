# Трекер рилсов

Единый список всех роликов: о чём каждый и на какой он стадии. **Перед новым сценарием** проверяем по колонке «Главная мысль» и по разделу «Занятые темы», что тема ещё не раскрыта. **После каждого шага** (снято, смонтировано, опубликовано) отмечаем здесь.

Обозначения: ✅ готово · 🟡 частично (см. примечание) · ⬜ нет
Сценарий: **60** — длинная версия 55–60 с (`REELS-60.md`), **30** — короткая (`REELS-10.md` / `BY-LOCATION.md`).
