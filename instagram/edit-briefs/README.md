# ТЗ на монтаж — 10 рилсов v3

Сценарии: `instagram/REELS-10.md` (полные, с пометками кадров `*…*` и разметкой [ХУК]/[ПОВТОРНАЯ ЗАЦЕПКА]/…). Суфлёр: `instagram/teleprompter.md`. Старое ТЗ (v1) устарело.

## Как снято
- Один ролик = один файл `01.mp4` … `10.mp4`, читается подряд. Между строками пауза 1–2 с.
- Ошибка: спикер говорит «заново» и повторяет строку → оставлять **последний** дубль (или лучший, если повторов несколько).
- Вставки — отдельные файлы `NN-ekran.mp4`, `08-vstavka.mp4`, `09-vyveska.mp4` и т.п.

## Общие требования
- 1080×1920, 30 fps, H.264 + AAC, ≈ −14 LUFS. Длина 30–40 с.
- Язык русский, транскрипция `ru` (ElevenLabs или Whisper). **Мат не запикивать.**
- Вырезать паузы, «заново» и неудачные дубли; темп быстрый, энергичный, не рубить концы слов.
- Субтитры на весь ролик, 2–4 слова, крупно. Отдельно — заголовки на экране (список у каждого ролика ниже), ≤ 6 слов, синхронно со словами.
- Безопасная зона: текст между y=230 и y=1440, справа 230 px свободно.
- Смена плана каждые 2–3 с (зум-ин/аут, вставка, стоп-кадр).
- Первый кадр — сразу движение + заголовок хука, без интро и логотипа.
- [ПОВТОРНАЯ ЗАЦЕПКА] — визуальный акцент (резкий зум/смена ракурса).
- [ФРАЗА-СКРИНШОТ] — стоп-кадр + крупный текст фразы на 1–1,5 с.
- Палитра бренда (сайт 360-digital.ru): жёлтый #FFC24B / #F5A623, тёмный #0F0F12, графит #1A1A1F, зелёный #16A34A для «хороших» цифр; шрифт Manrope (есть в `stories/fonts/` ветки `claude/compassionate-brown-q49v3k`).
- Без логотипов Яндекса; интерфейс Яндекс Карт — только из записей экрана спикера. Чужие телефоны/имена/номера машин — размыть.
- Музыка: тихая подложка без вокала или без музыки. Конец без заставки (зацикливание).
- Для каждого ролика — отдельный кадр-обложка 1080×1920 по описанию.
