# Принципы монтажа — накопленные правки пользователя

Обновлять после КАЖДОЙ итерации, где пользователь что-то поправил или где нашли ошибку. Читать перед каждым новым роликом.

## Звук и речь
- **Фраза должна быть законченной.** Конец фразы определять по громкости (паузе), а не по таймкодам Whisper — он ставит конец слова раньше реального. Пример: SP06 «…который мы получаем» обрезалось.
- **Вторая проверка после финального рендера (обязательно):** `python3 -I instagram/edits/tools/check_speech.py <final.mp4> <edit-decisions.json>` — перечитать расшифровку целиком: нет ли обрывов, «прилипших» слов следующей фразы («поэтому», «даже»), повторов, оговорок, бессмысленных начал. Найденное — исправить и перерендерить до отправки.
- Стык с громкостью >60 дБ с обеих сторон в `check_speech.py` — почти всегда обрезанное слово (SP11: «бюджет» вместо «бюджета»). Сдвигать конец отрезка до реальной паузы.
- **Последнее слово ролика:** функция `tight()` в cut.py подрезает конец по порогу громкости и может съесть тихий последний слог (SP11: «органики»). Для ПОСЛЕДНЕГО отрезка конец ставить вручную по громкости — в начале паузы после слова, до начала следующей фразы, без `tight()`.
- В конце ролика — 0,5–0,6 с тихого хвоста после последнего слова, голос с затуханием 0,08 с.
- Сомнительные утверждения (нет в справке Яндекса) — вырезать или помечать «из нашей практики». Пример: «ответил на отзыв = согласился».
- Не оставлять обещаний, которые зритель не получит («QR-код в конце», «промпт по ссылке»).

## Картинка
- Плашки субтитров — на груди (y≈1330), одна строка, 2–4 слова; не на лице/бороде.
- Графические карточки закрывают слайд целиком (тёмная рамка `box-shadow:0 0 0 40px`), без белых полосок.
- Плашки не должны наезжать друг на друга и на заголовок — проверять кадры финала.
- ID элементов графики не должны совпадать с ID субтитров (`c0…cN`) — иначе мигание (баг SP09).
- Имена авторов отзывов на слайдах — размывать.

- **Сырые дубли (говорящая голова):** берём последний чистый дубль каждой фразы; Whisper в сырой записи сдвигает таймкоды и «теряет» слова в паузах — границы отрезков ставить по громкости и перепроверять расшифровкой нарезки (07: терялись «принять», «Узнаёшь», «в выдаче»).
- **Ложные старты:** если человек начал фразу, остановился и сказал её заново — оставлять только второй (полный) заход; проверять по расшифровке нарезки, нет ли двух одинаковых начал подряд (07: «Узнаёшь только… / Узнаёшь только тогда…», «Без неё ты падаешь… / Без неё ты падаешь в выдаче»).
- **Кадр без ладоней:** кадрировать выше рук (07: crop 338×600 сверху из 464×848).
- **Запись экрана с чужой карточкой:** размывать название, адрес, сайт, телефоны; ввод своего номера не показывать. Если правка реально отправлена в чужую карточку — сказать пользователю.
- **Хук-заголовок на светлом фоне** — плашками (тёмная + жёлтая), не белым текстом.
- **Коллажи** — крупно (заголовок 80 px, пункты 56–64 px), чтобы не было пустоты.

## Обложки
- **Фотосессия для обложек:** https://disk.yandex.ru/d/oFarIA2kQYafyQ (238 фото, превью через API Диска). Для обложек роликов, снятых дома, брать фото оттуда под смысл заголовка (07: палец на зрителя — «ТВОЙ телефон…», Image00134).
- **Не грустное лицо:** на обложке — живой кадр (улыбка, поднятые брови, «вопрос»), не нейтрально-печальный. Если улыбок в записи нет — сказать и предложить снять 2–3 с улыбки отдельно.
- **Глаза открыты, взгляд в камеру** — перебирать кадры (8–16), выбирать вручную.
- Жёлтая подложка ключевого слова — узкая полоса (20–90 %), не перекрывает соседние строки.
- Заголовок ≤ 3 строк и не заходит на голову; стикер помещается по ширине.

## Процесс
- После каждого SP-ролика: `python3 instagram/edits/talk_usage.py` → строка «⏱ Лимит» в трекере (лимит 20 мин).
- Рецепт ролика (cut.py, build.py, edit-decisions.json, transcript.json, README) — в `instagram/edits/<код>/`, обложка — `instagram/covers/`, статус — `TRACKER.md`. Коммит и push в `main` после каждой итерации.
- Видео и `video-projects/` в git не идут (большие файлы), но всё, чтобы их пересобрать, — в репозитории.
