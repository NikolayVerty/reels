# SP01 · «2ГИС бесплатно покажет трафик конкурентов» — из выступления на Суровом Питерском форуме

Исходник: «Николай Вертий Суровый питерский.mp4» (Яндекс Диск, 59 мин, 1920×1080). Фрагмент 4:29–5:21, 38,5 с.
- `talk-0-20min.txt` — расшифровка первых 20 минут (faster-whisper medium), по ней идём дальше по порядку.
- `cut.py` — нарезка и вертикальная раскладка: слайд (crop 1162×660 @ 44,352) сверху, спикер (crop 640×600 @ 1236,352) снизу.
- `build.py` — графика HyperFrames: заголовок, плашки, «вопрос менеджеру», карточка сравнения 10-е vs 5–6-е место (цифры со слайда выступления).
